# Task 5: Titanic Data Analysis

## Objective
Analyze the Titanic dataset using Pandas.

## Steps Performed
1. Loaded Titanic dataset.
2. Filled missing Age values.
3. Filtered adult passengers with Fare > 30.
4. Created new features:
   - FamilySize
   - FarePerPerson
5. Used groupby() to calculate:
   - Average Fare by Passenger Class
   - Survival Rate by Passenger Class
   - Survival Rate by Gender

## Technologies Used
- Python
- Pandas
